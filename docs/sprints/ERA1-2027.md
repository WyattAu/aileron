## Hard gates (report-at-end list)

- **GATE-1 (S2):** agent profile is a *runtime* profile (`--agent`), not a
  cargo-feature compile-out. The binary still links wgpu/terminal deps;
  binary-size and dependency-surface goals are unmet. Compile-out requires
  splitting the bin's init graph behind `cfg(feature = "agent")` — a
  multi-day refactor touching every `window:`-dependent path.
- **GATE-2 (S4):** playwright-mcp baseline not executed in this environment
  (npx/npm availability unverified); harness supports `--target playwright`
  but the comparison row is doc-sourced, not measured.
- **GATE-3 (S7):** soak week (multi-hour stability under load) not runnable
  inside a sprint-session; bench numbers are spot measurements (n=12–16).
- **GATE-4 (S10):** walker-fidelity corpus (50 sites vs Chrome AX) requires a
  Chrome/CDP baseline collection pass; in-session validation now covers a
  12-site corpus (2026-10-31: 12/12 OK, 1300 refs, 96% named ratio; two
  legitimately-zero sites: RSS/XML feed and an SPA mid-load snapshot).
- **GATE-5 (S21–S23):** Online-Mind2Web/CAP task-list licensing + runner
  infrastructure; in-session evaluation is the smoke corpus + latency matrix.
- **GATE-6 (S24):** multi-session alpha is routing-level only; capability
  grants (κ/φ/ω) policy surface ships Era-2.
- **GATE-7 (S25):** MCP Registry listing + public site need publishing
  credentials/infrastructure outside this repo session.
- **GATE-8 (S16/S19):** wry 0.55.1 exposes no script-dialog handler, no
  file-chooser handler, and no print-to-PDF surface. Paths: (a) upstream wry
  feature, (b) raw webkit2gtk widget access via the pane's webkit child
  (the `webview_is_loading` downcast pattern), (c) servo hedge. Deferred to
  Era-2 Q1 with the observability stack otherwise complete.
