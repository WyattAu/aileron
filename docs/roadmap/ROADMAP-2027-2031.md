# ROADMAP 2027–2031 — Aileron: the formally-specified agent browser

**Companion docs:** `agent-native-split.md` (architecture), `RESEARCH-BASE-2026-Q4.md`
(literature ground truth), `.specs/` (YP convention), `gui-architecture.md` (human track).
**Cadence:** 2-week sprints; a quarter = 6 sprints + 1 hardening sprint; a year = 4 PIs.
**Standing lanes (every year):** quality gates (fmt/clippy/tests/docs + integration on push),
spec program (every feature lands as YP → Lean theorem or QA vector → runtime → benchmark),
self-healing ops (watchdog/service soak), memory-graph bookkeeping.

## The thesis

Agent performance is architecture-bound (2511.19477), the web needs a
browser-side enforcement point for agent safety (confinement, not detection),
and no browser has a formally specified agent surface (2601.17549's gap).
Aileron is that browser: **one codebase, two profiles** — the human browser and
the leanest, most feature-complete browser MCP daemon — with proofs where it
matters and measurements everywhere else.

## ERA 1 — 2027: The Agent Product (beat Playwright MCP on every metric)

**Goal:** aileron-agent is credible-by-default for any MCP client; the gap matrix
in `agent-native-split.md` closes to zero; benchmarks published.

### PI-1 (Q1, S1–S7): Lean core — the agent profile exists and is fast
- **S1–S2:** `--profile agent` compile-out (compositor, chrome, terminal, input
  router via cfg/features); boots offscreen webviews + MCP under Xvfb.
  *Gate:* binary builds, 24 tools green headless.
- **S3:** daemon packaging: systemd unit + OCI image; socket activation.
- **S4–S5:** metric harness vs playwright-mcp (startup, navigate→text p50/p95,
  idle RSS, tool coverage) — the `agent-native-split.md` target table becomes
  the CI dashboard. *Gate:* cold-attach <50ms, navigate→text p50 <500ms.
- **S6:** observation T0/T3 ship (title/url/epoch; readable text w/ adblock on).
- **S7:** hardening + soak week; GO/NO-GO on numbers.

### PI-2 (Q2, S8–S13): The ACI — snapshot & refs (the credibility feature)
- **S8–S10:** YP-AGENT-ACI-001 walker (in-page JS, tier T1/T2), 50-site corpus
  vs Chrome AX (≥95% interactive recall). `browser_snapshot`.
- **S11–S12:** epoch-unified refs: `click/type/hover/select/press_key/focus`
  accept `(epoch, ref)`; fail-closed + fresh-T1 attach (ACT-ACI-001 theorem →
  `ProofACI.lean`).
- **S13:** hardening; a11y test vectors in the QA matrix.

### PI-3 (Q3, S14–S20): Full actuation + observability parity
- **S14–S15:** bulk transactions (`bulk_act`) with per-action status; token/latency
  win reproduced against the 2511.19477 numbers on our harness.
- **S16:** `wait_for` (text/textGone/time) over the epoch gate; `handle_dialog`,
  `upload_file` (WebKit script-dialog + file-chooser signals).
- **S17:** console ring (`browser_console_messages`); network log via
  user-script fetch/XHR instrumentation (`browser_network_requests`).
- **S18:** cookies/storage (`webkit_website_data_manager`), downloads tools.
- **S19:** `browser_pdf_save` (print-to-PDF); `drag`, `pan` primitives.
- **S20:** hardening; tool count ≥34, zero capability flags.

### PI-4 (Q4, S21–S26): Prove it — evaluation era
- **S21–S23:** benchmark harness runs Online-Mind2Web-class task lists + CAP
  cross-site set; publish the latency/memory/coverage matrix.
- **S24:** multi-session alpha (YP-MCP-SESSIONS-002 routing: focus sets,
  per-(session,pane) epochs).
- **S25:** docs/site: "the browser for agents" — spec system, proofs, matrices
  published; MCP Registry listing.
- **S26:** era review: metric gates audited; Year-2 PI drafts.

**Era-1 exit gates:** snapshot recall ≥95% on corpus; navigate→text p50 <500ms;
idle RSS <350MB @4 panes; Online-Mind2Web-class task success ≥ best published
AX-based agent; 0 unhandled-defect weeks.

## ERA 2 — 2028: Scale & Trust (multi-agent, confinement, formal depth)

- **Q1:** multi-session GA — capability grants/delegation (κ, φ, ω), consent
  tooling, isolation theorem (EXT-PROP-MCP-002) in Lean; team-server alpha
  (one daemon, many agents, per-agent workspaces).
- **Q2:** YP-SEC-CONFINEMENT-001 lands: dispatcher policy classes, structural
  taint, consent channel; BrowseSafe-Bench-class vectors in CI; policy profiles.
- **Q3:** environment memory — workspace checkpoint/restore/diff as agent tools
  (AgentRewind pattern); PRO-LONG-style programmatic query tools
  (`workspace_query`); session-aligned checkpoints.
- **Q4:** WebMCP integration spike (broker pages' tools to agent sessions —
  the standard window; Chromium gates behind Gemini, we don't); formal program:
  `ProofConfine.lean` (ACT-CONF-001), MCP-spec deviation notes published.

**Era-2 exit gates:** injection vectors 100% confined in CI; two-agent
workflows stable 8h; workspace checkpoint/restore byte-exact; WebMCP demo on
real sites.

## ERA 3 — 2029: Platform & Ecosystem

- **Q1:** distribution: aileron-agent as the embeddable browser for agent
  frameworks (Browser-Use/LangGraph/Claude/OpenCode integrations); managed
  fleet mode (N daemons, scheduler API).
- **Q2:** profile SDK: site-specialized agents (2511.19477's "specialization as
  defense") — packaged (walker profiles, policies, tool subsets) per domain.
- **Q3:** enterprise: SSO, audit log (every action + provenance τ), policy
  as code (typed preconditions exported), compliance pack.
- **Q4:** human-browser track resumes as product polish (gui-architecture
  decision executed: egui layer or validated status quo); shared core gains
  servo-hedge evaluation (WebKitGTK risk review vs servo maturity).

**Era-3 exit gates:** 10k weekly daemon launches (self-hosted telemetry opt-in);
3 framework integrations first-party; audit trail complete (κ, τ, Γ recorded).

## ERA 4 — 2030: Frontier

- Self-improving loops: failure telemetry → walker/policy/profile improvements
  proposed as YP patches (human-approved; the loop institution automates itself).
- Formal program expansion: full MCP-surface contract model in Lean (every tool,
  pre/post as theorems — YP-MCP-CONTRACTS-001 fully realized); confinement
  hyperproperties (per-session non-interference).
- Performance frontier: profile-agent binary <30MB, cold-attach <20ms,
  100-pane fleet density; GPU-free rendering path for pure-agent workloads.
- Standards: aileron as WebMCP reference broker; co-author browser-agent
  safety profile (confinement) into the MCP spec discussion.
